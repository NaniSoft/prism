Prism is a token pipeline, a React library you compose, and documentation that
reads the build. This Section is the way in: what the system is, how its three
layers relate, how to compose from it, how to theme it, and what an agent reads.

- [Quickstart](/overview/quickstart) installs Prism and renders the first Component
  and Block.
- [Architecture](/overview/architecture) explains the package boundary and the
  catalogue.
- [Composition](/overview/composition) helps you choose the smallest layer that owns
  the job.
- [Theming](/overview/theming) covers packs, modes and flash-free switching.
- [Using LLMs](/overview/using-llms) wires an agent to the same source.
- [Brand policy](/overview/brand) states the licence and the brand rules.
