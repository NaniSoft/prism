description: "Task guides for adopting Prism: from install and theming to architecture, composition and the agent surface."
---

These guides cover the tasks a consumer repeats. They describe the system as it
is now: one package, one stylesheet, packs and modes as markup attributes, and a
catalogue that feeds the docs and the agent surface from one list.

- [Quickstart](/docs/quickstart) installs Prism and renders the first Component
  and Block.
- [Architecture](/docs/architecture) explains the package boundary and the
  catalogue.
- [Composition](/docs/composition) helps you choose the smallest layer that owns
  the job.
- [Theming](/docs/theming) covers packs, modes and flash-free switching.
- [Agent workflow](/docs/agent-workflow) wires an agent to the same source.
- [Brand policy](/docs/brand) states the licence and the brand rules.
