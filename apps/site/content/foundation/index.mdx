---
title: Foundation
description: "The token families Prism ships, each a live reader of the emitted cascade."
---

The Foundation is the token families. Each page reads the emitted cascade rather
than restating a value, so a token change is reflected here the moment the token
package is rebuilt.

- [Colors](/foundation/colors) reads the semantic contract and the foundation
  ramps.
- [Iconography](/foundation/iconography) covers interface icons and sizing.
- [Radii](/foundation/radii) reads the radius scale derived from one base.
- [Shadows](/foundation/shadows) reads the three authored elevation steps.
- [Spacings](/foundation/spacings) reads the spacing scale.
- [Typography](/foundation/typography) reads the type, leading, tracking and
  weight tokens.
- [Motion](/foundation/motion) reads the duration and easing tokens.
- [Variables](/foundation/variables) is the full token browser.

The packs and modes these tokens resolve against are rendered side by side on the
[themes page](/foundation/themes).
