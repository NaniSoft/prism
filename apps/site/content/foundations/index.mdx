---
title: Foundations
description: "The token families Prism ships, each a live reader of the emitted cascade."
---

Foundations are the token families. Each page reads the emitted cascade rather
than restating a value, so a token change is reflected here the moment the token
package is rebuilt.

- [Colors](/foundations/colors) reads the semantic contract and the foundation
  ramps.
- [Iconography](/foundations/iconography) covers interface icons and sizing.
- [Radii](/foundations/radii) reads the radius scale derived from one base.
- [Shadows](/foundations/shadows) reads the three authored elevation steps.
- [Spacings](/foundations/spacings) reads the spacing scale.
- [Typography](/foundations/typography) reads the type, leading, tracking and
  weight tokens.
- [Motion](/foundations/motion) reads the duration and easing tokens.
- [Variables](/foundations/variables) is the full token browser.

The packs and modes these tokens resolve against are shown on the
[themes page](/themes).
