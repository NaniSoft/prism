## Overview

Hero01 is the opening band of a marketing page: an optional eyebrow, a headline,
an optional supporting line, and up to two actions. The `01` suffix is the
variant ordinal of the hero family.

It has two forms and they are one Block. The copy can sit centered over the
container, which suits a page whose claim is a sentence. Or it can sit in the
left column of a two-column band with a live figure in the right, which suits a
product whose claim is a mechanism. Passing `instrument` picks the second form.

Every string is a prop. The block ships no eyebrow and no headline, because a
hero with hardcoded copy makes every consumer inherit a claim about their own
product.

## Usage

```tsx
import { Hero01 } from '@nanisoft/prism-ui/blocks/hero-01'

<Hero01
  eyebrow="Now available"
  title="Ship your interface faster"
  description="A token-driven component library you compose without writing CSS."
  actions={[
    { label: 'Get started', href: '/docs' },
    { label: 'Read the guides', href: '/docs/guides', variant: 'outline' },
  ]}
/>
```

The split form, with a figure that shows the product running:

```tsx
import { Hero01 } from '@nanisoft/prism-ui/blocks/hero-01'
import { InstrumentPanel01 } from '@nanisoft/prism-ui/blocks/instrument-panel-01'
import { PulseGraph } from '@nanisoft/prism-ui/components/pulse-graph'

<Hero01
  headingLevel="h1"
  eyebrow="nanisoft"
  title="Software that builds software."
  description="One issue goes in. A reviewed pull request comes out."
  actions={[{ label: 'Follow the build', href: '/blog' }]}
  instrument={
    <InstrumentPanel01 label="the loop, running" stateLabel="live">
      <PulseGraph
        nodes={STAGES}
        relations={EDGES}
        label="The build loop, from issue to merged pull request"
      />
    </InstrumentPanel01>
  }
/>
```

## Guidelines

### When to use

Use Hero01 as the first band of a page whose purpose is to introduce a product
or a release. It works when there is one clear headline and one clear next
action.

Use the split form when the product does something rather than being something.
A pipeline that runs, a surface that is captured, a fleet that is observed: each
of those is a mechanism, and a mechanism reads better shown than described. The
figure should be one that would still be true with every animation stopped, so
what the reader gets from it is the claim and the motion is only the emphasis.

### When not to use

Do not use Hero01 inside an application screen. It is a marketing composition,
and its generous layout competes with the task the screen exists to support.

Do not use it twice on one page. A second hero splits the reader's attention and
leaves two claims competing for the same position.

Do not use it when the headline is really a section heading. Use `SectionHeading`
inside `Section` instead.

Do not pass a figure that is only interesting while it moves. A slot that reads
as empty in a still frame is a decoration with a slot, and this system does not
author those.

### Best practices

- Pass one primary action and at most one supporting action. More than two
  actions turn a decision into a menu.
- Give the first action `default` and the second `outline`. The block already
  defaults to that order.
- Give every action an `href`. An action with a destination renders as a real
  link, because a control that looks like a link and is not one is a dead end.
  An action with no destination renders as a `Button`, which is inert here by
  design: a Block ships no behaviour.
- Set `headingLevel="h1"` when the hero is the page's top-level heading. Use the
  default `h2` when the page already owns an `h1`.
- Pass an eyebrow only when it is true and current. It renders nothing when
  absent, so the honest state is no eyebrow.
- Wrap the figure in `InstrumentPanel01`. A bare figure on the page ground reads
  as an illustration; the same figure in a panel reads as an instrument, which
  is what it is.

### Content guidelines

- Keep the headline under about eight words and let it wrap to two lines at
  most.
- Write the headline as an outcome, not a feature name.
- The description is one sentence and states who the product is for or what
  changes if the reader continues.
