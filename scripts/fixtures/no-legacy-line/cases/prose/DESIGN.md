# Using the design system

This document is a living instruction, not a record, so naming the vendor here
is a finding: an instruction that names Ant Design teaches the reader to reach
for it. Import the library and compose it instead.

```tsx
import { Button } from '@nanisoft/prism-ui/components'
```

Readers migrating from the previous system are sent to `MIGRATION.md`, which is
the record of what changed and is allowed to name what it replaced.
